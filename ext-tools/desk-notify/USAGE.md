# Sending to a desk-notify member

A desk-notify member is a person's desk: whatever you send it shows up as a
desktop notification on the machine where it was set up. The notification
names you (and the team) and shows the start of your message, about 120
characters on one line. The full text stays in the team's history, where the
person reads it.

There is no reply on success. If the notification cannot be shown, you get one
reply naming why (for example, no notifier on that machine).
